# Origin Launcher (стиль OriginOS 7)

## Как получить APK
**Вариант 1 — Android Studio:** File → Open → папка проекта → Build → Build APK(s).
Файл: `app/build/outputs/apk/release/app-release.apk`.

**Вариант 2 — без установки чего-либо:** залей проект в GitHub-репозиторий →
вкладка Actions → Build APK → скачай артефакт `OriginLauncher-apk`.

## Установка
Установи APK, нажми кнопку «Домой» → выбери Origin Launcher → «Всегда».

## Управление
- Свайп влево/вправо — страницы с параллаксом
- Свайп вверх — библиотека приложений (фон размывается)
- Тап по иконке — пружинное нажатие и раскрытие окна из иконки
- Кнопка «Домой» / «Назад» — закрыть библиотеку
